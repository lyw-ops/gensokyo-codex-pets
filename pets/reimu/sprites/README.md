# Reimu sprite assets

No sprite assets exist yet. This is intentional.

When art begins, keep editable source files separate from exported row strips and the assembled atlas. Use descriptive state names matching `docs/codex-pet-format.md`; do not use commercial game filenames or imported commercial sprite data.

A final local package candidate must include a transparent 1536×2288 PNG or WebP atlas, pass deterministic validation, and receive visual QA at actual pet size. Generated intermediates and QA renders belong in ignored build/QA directories unless maintainers explicitly decide to preserve them.
